APK + EXE BANANE KA TARIQA (free, GitHub se)

1. github.com par free account banayein, New Repository banayein (naam: cba-test).
2. Is poore folder ki saari files repository me upload karein (".github" folder bhi, usme build.yml hai).
3. Repository me "Actions" tab kholein -> "Build APK and EXE" -> "Run workflow".
4. 5-10 minute baad usi run ke neeche "Artifacts" me do files milengi:
   - windows-exe  (setup .exe: Windows 7 / 10 / 11, 32-bit aur 64-bit)
   - android-apk  (app-debug.apk: mobile me install karein)
5. Mobile me APK install karte waqt "Install unknown apps" allow karein.

Live sync (teacher dashboard): www/index.html me  var CFG="";  ke andar Firebase Realtime Database ka URL likhein, phir upar wale steps dobara chalayein.
